Mivaan - TTD Auto Fill Privacy Policy

Last updated: September 23, 2026

Mivaan - TTD Auto Fill is a Chrome extension designed to help users fill supported TTD booking form fields using information saved by the user.

Information Stored

The extension allows users to save information such as:

  • Name
  • Email address
  • Mobile number
  • City
  • State
  • Country
  • PIN code
  • Pilgrim name
  • Pilgrim age
  • Gender
  • Photo ID type
  • Photo ID number

This information is provided voluntarily by the user.

How Information Is Used

The information is used to provide the extension's profile management and form auto-fill functionality.

The extension allows users to create, edit, duplicate, delete, import, and export saved profiles.

Where Information Is Stored

Profile information is stored using Chrome's local extension storage (chrome.storage.local) on the user's device/browser profile.

Mivaan does not operate a server for storing this profile information.

Data Sharing

Mivaan does not sell, rent, or share users' saved profile information with advertisers or data brokers.

The extension does not intentionally transmit saved profile information to a Mivaan server.

Payment Information

Mivaan does not request or store credit-card, debit-card, UPI, banking passwords, or other payment credentials.

Users should enter payment information only on the appropriate payment page and should never save payment credentials in the extension.

User Control

Users can manage their saved profiles through the extension's Options page. Profiles can be edited or deleted by the user.

The extension also provides profile export functionality, which allows users to create a backup file containing their saved profile information. Users are responsible for protecting any exported backup file.

Third-Party Websites

Mivaan may interact with supported TTD booking webpages to provide its form-filling functionality.

Mivaan - TTD Auto Fill is an independent browser extension and is not affiliated with, sponsored by, or endorsed by Tirumala Tirupati Devasthanams (TTD), unless explicitly stated otherwise.

Users should review the privacy policies and terms of any third-party website they visit.

CAPTCHA and Security

Mivaan does not intentionally bypass CAPTCHA or other security mechanisms.

Users remain responsible for completing any CAPTCHA, verification, authentication, payment, or other security steps required by the website.

Children's Privacy

Mivaan is not specifically directed toward children, and we do not knowingly collect personal information from children through a Mivaan server.

Changes to This Privacy Policy

This privacy policy may be updated when the extension's functionality or data practices change. The latest version will be published on this page.
